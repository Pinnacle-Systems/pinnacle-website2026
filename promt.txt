```jsx

```


* Buttons


```text

tracking-*
max-w-*
```

Make every image responsive.


* Margin
* Gap
* Section spacing

### 7. Responsive Widths

Avoid unnecessary fixed widths such as:

```text
w-[700px]
w-[800px]
w-[1000px]
```

when they can cause overflow.

Prefer:

```text
w-full
max-w-*
```

For example:

```jsx
w-full max-w-xl
```

If a fixed width is required for the design, make it responsive:

```jsx
w-full sm:w-[400px] lg:w-[500px]
```

---

### 8. Responsive Height

Avoid fixed heights for content whenever possible.

Do not use something like:

```text
h-[600px]
```

if the content can naturally determine the height.

Prefer:

```text
min-h-*
h-auto
```

or responsive heights where genuinely necessary.

Make sure content never gets cut off on smaller screens.

---

* Make images smaller
* Make buttons easy to tap
* Make text wrap correctly
* Keep content inside the viewport

```jsx

```

---

### 10. Tablet Layout

For tablets:

* Use available width efficiently
* Use 1–2 column layouts where appropriate
* Increase spacing slightly compared with mobile
* Keep typography readable
* Prevent excessive empty space

---

### 11. Laptop/Desktop Layout

For larger screens:

* Use multiple columns where appropriate
* Increase spacing naturally
* Allow images to become larger
* Keep content centered
* Prevent the component from becoming excessively wide

Use:

```text

mx-auto
```

where appropriate.

### 12. Prevent Overflow

The component must not create unwanted horizontal scrolling.

Check carefully for:

* Fixed widths
* Fixed heights
* Large images
* Absolute-positioned elements
* Negative margins
* `translate-x`
* Large headings
* Buttons
* Long text
* Decorative elements

Fix the actual overflowing element instead of blindly adding:

```text
overflow-x-hidden
```

Follow this general approach:

```text

sm   → Large mobile
md   → Tablet
lg   → Laptop
xl   → Desktop
2xl  → Large desktop
```

Do not add unnecessary breakpoints everywhere.
